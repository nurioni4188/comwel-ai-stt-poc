# STT PoC 1차 검증 배치 10건

기준선: `v0.7.0-stt-classification-review`

## 목적

기능 추가가 아니라 현재 PoC의 실증 검증을 위한 첫 배치다. 10건을 완료한 뒤 중간 분석을 수행하고, 결과에 따라 나머지 20건의 구성을 조정한다.

## 검증 흐름

각 케이스는 아래 순서로 동일하게 처리한다.

1. 지정 조건으로 음성 녹음
2. STT 실행 및 전사 완료 확인
3. AI 요지/정제본 생성
4. 담당자 수정본 저장 및 확정
5. v0.5.0 품질평가 저장
6. v0.6.0 AI 참고분류 실행
7. v0.7.0 담당자 분류 확정 또는 정정
8. 오류·특이사항 기록

## 10건 구성

| ID | 유형 | 핵심 검증 |
|---|---|---|
| B01-01 | 이직사유 정정 | 일반 민원, 정정·서류·절차 |
| B01-02 | 산재 휴업급여 | 전문용어, 사업주 확인 |
| B01-03 | 숫자·날짜·금액 | 수치 인식 정확도 |
| B01-04 | 고령자형 반복 발화 | 반복 제거와 요지 보존 |
| B01-05 | 빠른 발화 | 단어 누락·문장 경계 |
| B01-06 | 지역 억양 | 피보험자격 핵심어 인식 |
| B01-07 | 배경소음 | 소음 환경 STT 안정성 |
| B01-08 | 비원어민 한국어 | 발음 다양성 |
| B01-09 | 의도 불명확 | needs_review 적절성 |
| B01-10 | 복합 민원 | 복수 쟁점 보존·분류 한계 |

## 1차 합격 기준

표본 10건은 통계적 결론을 위한 수가 아니므로 ‘기준선 탐색’으로 해석한다.

- STT 완료율: 10/10 목표
- 시스템 오류·timeout: 0건 목표
- 핵심어 누락: 케이스별 `pass_focus` 기준 확인
- 품질평가 `정확 + 경미한 수정`: 80% 이상을 초기 목표로 사용
- 자동분류: 담당자 확정값과 업무영역 일치율 기록
- 분류가 애매한 B01-09/B01-10은 무리한 확정보다 `needs_review` 또는 담당자 정정을 정상 동작으로 본다.
- 모든 실패는 재시도 전에 원인 분류를 먼저 기록한다.

## 실패 원인 코드

- `STT_RECOGNITION`: 음성 인식 오류
- `STT_SYSTEM`: 업로드·CLOVA·callback·timeout 오류
- `SUMMARY_OMISSION`: 핵심 사실/요청 누락
- `SUMMARY_DISTORTION`: 사실 왜곡·추가
- `CLASSIFICATION_WRONG`: 업무영역 또는 쟁점 오분류
- `SOURCE_AMBIGUOUS`: 원문 자체가 불명확
- `UX_WORKFLOW`: 버튼·상태·저장 흐름 문제
- `OTHER`: 기타

## 중요 원칙

- 개인정보가 포함된 실제 민원 음성을 사용하지 않는다. 1차 배치는 합성된 테스트 문장을 사람이 읽어 녹음한다.
- 비원어민 케이스는 억양을 흉내 내기보다 실제 비원어민 참여자가 있는 경우에만 실시한다. 그렇지 않으면 B01-08은 일반 발화로 먼저 실행하고 2차 배치에서 실제 참여자로 교체한다.
- 자동분류는 참고 분류이며 자동처분·자격판단·자동배정에 사용하지 않는다.
- 10건 완료 후 즉시 중간분석을 수행한 뒤 2차 20건 설계를 확정한다.
