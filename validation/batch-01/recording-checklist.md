# Batch 01 녹음·실행 체크리스트

## 공통 녹음 규칙

- 파일명: `B01-01.m4a` ~ `B01-10.m4a`
- 한 파일에는 해당 케이스 문장만 포함
- 시작·끝 1초 정도의 자연스러운 무음 허용
- 같은 케이스를 여러 번 녹음한 경우 최종 선택본만 PoC에 업로드
- 실제 개인정보, 실제 사건번호, 실제 주민번호·전화번호 사용 금지

## 케이스별 녹음 조건

- [ ] B01-01 일반 속도·조용한 방
- [ ] B01-02 일반 속도·전문용어를 자연스럽게 발음
- [ ] B01-03 날짜와 금액을 또박또박 말하되 숫자를 생략하지 않음
- [ ] B01-04 평소보다 천천히, 반복 문장을 그대로 포함
- [ ] B01-05 평소보다 빠르게, 문장 사이 쉬는 시간 최소화
- [ ] B01-06 실제 사용하는 지역 억양이 있으면 적용, 억양을 인위적으로 과장하지 않음
- [ ] B01-07 일정한 생활소음 또는 사무실 소음을 배경에 두고 녹음
- [ ] B01-08 실제 비원어민 참여자가 없으면 일반 발화로 대체 후 비고 기록
- [ ] B01-09 모호한 원문을 임의로 명확하게 고쳐 읽지 않음
- [ ] B01-10 두 쟁점을 하나의 자연스러운 발화로 연결

## 10건 완료 후 중간분석

다음 값은 Supabase DB에서 집계한다.

- STT 완료/실패 건수
- 품질평가 4단계 분포
- 평균 수정률
- 평균 검토시간
- STT 인식 오류 영향 건수
- 자동분류 업무영역 정확도
- 쟁점 완전일치율
- 담당자 정정률
- needs_review 비율
- 오류 유형별 건수
- 케이스 조건별 실패 패턴

10건 완료 후 2차 배치 20건은 이 결과를 바탕으로 난이도와 케이스 비중을 조정한다.
