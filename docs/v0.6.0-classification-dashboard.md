## 자동분류 원칙
자동분류는 업무 라우팅 참고용이며 자동처분·자격판단·법률판단이 아니다.

업무영역 9개:
- 산재보험
- 고용보험
- 보험가입·자격
- 보험료·징수
- 임금채권
- 복지
- 증명·일반민원
- 기관운영
- 기타

쟁점은 신청 가능 여부, 필요서류, 사업주 확인, 절차, 처리기간, 사유 설명, 이의신청, 정정·변경, 소급 적용, 지급·급여, 기타로 제한한다.

`confidence < 0.75`이면 `needs_review=true`로 강제해 담당자 확인을 요구한다.
