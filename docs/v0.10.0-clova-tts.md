# v0.10.0 CLOVA Voice TTS

## 목표
승인근거 기반으로 실제 생성된 AI 답변만 CLOVA Voice로 음성 재생한다.

## 환경변수
- `CLOVA_VOICE_CLIENT_ID`: NAVER Cloud AI·NAVER API Application Client ID
- `CLOVA_VOICE_CLIENT_SECRET`: 해당 Application Client Secret
- `CLOVA_VOICE_SPEAKER`: 선택, 기본값 `nara`

## 안전 통제
- RAG 생성 성공 답변만 TTS 가능
- `rag_answer_runs.answer_hash`와 요청 텍스트 SHA-256이 일치해야 함
- fallback/담당자 확인 건은 TTS 버튼을 표시하지 않음
- TTS 결과 파일은 DB/Storage에 영구 저장하지 않고 브라우저에 즉시 전달
- `tts_runs`에는 실행 상태와 메타데이터만 기록
- anon/authenticated 직접 DB 접근 금지, service_role 서버 접근만 허용
- 한국어 답변은 CLOVA Voice 1회 제한에 맞춰 최대 2,000자로 제한

## E2E 합격기준
1. 승인근거 기반 답변 생성 후 `음성으로 듣기` 버튼 노출
2. 버튼 클릭 시 MP3 음성 재생
3. `음성 정지` 정상 동작
4. 동일 답변 다시듣기 가능
5. 자동답변 보류 건에는 TTS 버튼 없음
6. 변조된 텍스트/다른 ragRunId 조합은 answer guard로 차단
7. `tts_runs.status=completed` 로그 확인
