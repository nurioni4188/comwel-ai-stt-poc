# v0.8.0 승인근거 기반 AI 답변 엔진 설계

## 목표
민원 질문을 입력받아 승인된 근거만 검색하고, 검색된 근거가 충분한 경우에만 AI 답변 초안을 생성한다.

## 처리 흐름
1. 질문 입력
2. 개인정보 입력 경고
3. 승인된 지식 검색
4. 근거 충분성 판단
5. 근거가 충분하면 AI 답변 생성
6. 근거가 없거나 불충분하면 담당자 확인 필요로 전환
7. 답변과 함께 사용 근거·출처·승인상태 표시

## 안전 원칙
- `approval_status = approved`인 지식만 검색 대상
- 현재 웹 PoC는 별도 사용자 인증이 없으므로 기본값으로 `is_test_fixture = true`인 승인자료만 사용
- 실제 내부 승인자료 사용은 서버 환경변수 `RAG_ALLOW_INTERNAL_APPROVED=true`와 별도 인증/접근통제 검토 후 허용
- 승인 근거 0건 또는 관련성 기준 미달이면 생성형 답변 금지
- 개인 사건의 인정·지급·처분 결과를 단정하지 않음
- 답변은 내부직원 참고용 PoC이며 실제 민원 발송·자동처분하지 않음
- 질문 원문은 DB에 저장하지 않고 SHA-256 hash와 사용 근거 ID 등 최소 실행 메타데이터만 기록
