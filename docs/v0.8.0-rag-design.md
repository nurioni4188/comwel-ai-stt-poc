# v0.8.0 승인근거 기반 AI 답변 엔진 설계

## 목표
민원 질문을 입력받아 승인된 근거만 검색하고, 검색된 근거가 충분한 경우에만 AI 답변 초안을 생성한다.

## 처리 흐름
1. 질문 입력
2. 개인정보·금지표현 점검
3. 승인된 지식 검색
4. 근거 충분성 판단
5. 근거가 충분하면 AI 답변 생성
6. 근거가 없거나 불충분하면 담당자 확인 필요로 전환
7. 답변과 함께 사용 근거·출처·승인상태 표시

## 안전 원칙
- `approval_status = approved`인 지식만 검색 대상
- 승인 근거 0건이면 생성형 답변 금지
- 개인 사건의 인정·지급·처분 결과를 단정하지 않음
- 답변은 내부직원 참고용 PoC이며 실제 민원 발송·자동처분하지 않음
- 검색·답변 로그는 민원 원문 전체를 저장하지 않고 최소 메타데이터 중심으로 설계
