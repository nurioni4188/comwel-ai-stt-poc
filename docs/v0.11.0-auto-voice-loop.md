# v0.11.0 Automatic Voice Loop

## 목표
기존의 수동 버튼형 흐름을 한 번 시작하면 자동으로 순환하는 음성상담 PoC로 연결한다.

`민원인 발화 → CLOVA STT → 승인근거 RAG → AI 답변 → Browser TTS → 다음 발화 대기`

## 동작
- 최초 1회 `자동 상담 시작`으로 마이크 권한 획득
- 각 턴은 8초 발화창으로 녹음
- 8초 후 자동 녹음 종료 및 기존 `/api/stt-ingest`/세션 완료 흐름 사용
- STT 완료 시 인식문을 현재 질문으로 RAG 자동 호출
- 승인근거 기반 답변이 생성되면 Browser TTS로 자동 재생
- TTS가 끝난 뒤 다음 8초 발화창 자동 시작
- AI 음성 재생 중에는 마이크를 사용하지 않아 자기음성 재인식 방지
- 승인근거 부족, 개인정보 차단, STT/RAG/TTS 오류 시 자동 루프 중지

## 안전 원칙
- 실제 민원 원문 및 개인정보 입력 금지
- 승인근거가 없는 답변은 음성으로 자동 재생하지 않음
- 자동처분·자동조사·자동발송 없음
- 브라우저 세션의 최근 6턴만 RAG 문맥에 전달
- 전화망/SIP 연동 없음

## v0.11.0 합격기준
1. Preview build READY / HTTP 200
2. `자동 음성상담` 탭 노출
3. 자동 상담 시작 후 마이크 녹음 시작
4. 8초 후 별도 버튼 없이 STT 처리로 전환
5. STT 인식문으로 RAG 자동 호출
6. 승인근거 답변을 Browser TTS로 자동 재생
7. TTS 종료 뒤 자동으로 다음 발화 대기
8. 근거 부족 질문은 자동응답을 중지하고 담당자 확인 상태 표시
9. 자동 상담 중지 버튼으로 언제든 루프 종료
