# v0.15.0 Live Telephony E2E Baseline

## 완료 정의

실제 시험 전화 한 통에서 아래 전체 경로를 통과해야 v0.15.0을 병합/태그한다.

1. 검증된 시험 휴대전화 → Twilio Trial Voice 번호/시험경로
2. Twilio `<Connect><Stream>` → 공개 WSS Media Gateway
3. Twilio `audio/x-mulaw`, 8 kHz mono → Gateway PCM16/16 kHz 변환
4. 8초 메모리 발화 버퍼 → WAV
5. 기존 `/api/stt-ingest` → CLOVA STT
6. 기존 `/api/stt-rag-answer` → 승인근거 검색/AI 답변
7. OpenAI `/v1/audio/speech` Server TTS
8. PCM → μ-law/8 kHz 변환
9. Twilio `media` + `mark` → 수화기에서 AI 음성 청취
10. 다음 발화 1회 또는 근거부족 fallback 확인

## 현재 자동 구현 완료

- `gateway/liveBridge.mjs`
- 전화 오디오 8초 메모리 버퍼링
- WAV 헤더 생성
- `/api/stt-ingest` 호출
- `/api/stt-rag-answer` 호출 및 최근 6턴 history 전달
- 승인근거 답변 → Server TTS → Twilio 송출
- 근거 부족 → 담당자 확인 안내 후 live loop stop
- AI 재생 중 inbound audio 무시
- Twilio `mark` 수신 후 다음 청취 버퍼 초기화
- `/v1/sessions` 상태 진단 endpoint
- 실제 통화 원시 오디오 파일/DB 저장 없음

## Gateway 필수 환경변수

```text
TELEPHONY_PROVIDER=twilio
LIVE_E2E_ENABLED=true
TWILIO_AUTH_TOKEN=<Twilio Console 값>
PUBLIC_MEDIA_WSS_URL=wss://<gateway-host>/v1/media
OPENAI_API_KEY=<existing OpenAI API key>
AI_APP_BASE_URL=https://comwel-ai-stt-poc.vercel.app
LIVE_TURN_MS=8000
```

## 별도 Gateway 배포 요구사항

- Node.js 20+
- 지속형 WebSocket 지원
- HTTPS/WSS 공개 URL
- TCP 443 외부 접근 가능
- 프로젝트 Root Directory: `gateway`
- Start command: `npm start`
- Health check: `GET /health`

Vercel Serverless Functions에는 장시간 Media WebSocket을 배포하지 않는다.

## Twilio Trial 설정

- Trial 가입 후 본인 휴대전화 번호 검증
- Voice Trial에서 할당된 시험 번호/허용된 번호 조합 확인
- Voice webhook/TwiML 요청 URL을 `https://<gateway-host>/v1/twiml`로 설정
- TwiML이 `<Connect><Stream url="wss://<gateway-host>/v1/media" />`를 반환하는지 확인
- trial 제한 때문에 검증된 전화번호만 사용

## E2E 시험 문장

첫 질문:

`개인정보가 포함된 실제 민원 원문을 입력해도 되나요?`

기대 결과:

- CLOVA STT 인식
- approved fixture 근거 검색
- AI 답변 생성
- 수화기에서 Server TTS 음성 청취

후속 질문:

`그럼 주민등록번호가 들어간 내용도 입력하면 안 되나요?`

기대 결과:

- 이전 대화 문맥 활용
- 승인근거 답변
- 수화기 자동 음성응답

새 주제:

`회사에서 이직사유를 권고사직으로 정정할 수 있나요?`

기대 결과:

- 승인근거 부족
- 담당자 확인 필요 음성 안내
- 자동 loop 중지
