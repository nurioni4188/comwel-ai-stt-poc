# v0.10.0 Browser TTS Baseline

## 목표
승인근거 기반으로 생성된 AI 답변을 브라우저 내장 Web Speech API(`speechSynthesis`)로 비용 없이 음성 재생한다.

## 구현 원칙
- 외부 TTS API를 호출하지 않는다.
- 별도 Client ID / Secret / 유료 구독이 필요 없다.
- AI 답변 텍스트는 브라우저에서만 음성 합성된다.
- RAG 생성 성공 답변에만 `음성으로 듣기` 버튼을 표시한다.
- 자동답변 보류/담당자 확인 건은 음성으로 읽지 않는다.
- 한국어(`ko-KR`) 음성을 우선 선택하고, 사용 가능한 한국어 voice가 없으면 브라우저 기본 음성을 사용한다.
- `음성 정지`와 같은 답변 `다시듣기`를 지원한다.
- 대화 초기화 시 진행 중 음성도 정지한다.

## 비용/데이터
- TTS 자체 외부 API 비용: 0원
- TTS용 서버 환경변수: 없음
- TTS 음성파일 저장: 없음
- TTS 실행로그 DB 저장: 없음
- 기존 RAG 질문/답변 데이터 처리 원칙은 v0.9.0과 동일하게 유지한다.

## 호환성
Web Speech API 지원 여부와 실제 음색은 브라우저/운영체제에 따라 다를 수 있다. PoC 기준 브라우저는 Chrome/Edge를 우선으로 한다.

## E2E 합격기준
1. 승인근거 기반 답변 생성 후 `음성으로 듣기` 버튼 노출
2. 버튼 클릭 시 한국어 음성 재생
3. `음성 정지` 정상 동작
4. 같은 답변을 다시 클릭하면 다시듣기 가능
5. 자동답변 보류 건에는 TTS 버튼 없음
6. 대화 초기화 시 재생 중 음성 정지
7. 외부 TTS 네트워크/API 호출 및 TTS용 환경변수 없음
