# v0.14.0 Provider + Server TTS Integration Baseline

## 목표

v0.13.0의 독립 Media Gateway에 첫 실제 provider 구현체와 server-side TTS 구현체를 연결한다. 실제 전화번호 구매나 유료 통화를 발생시키기 전에 프로토콜, 오디오 변환, 보안 검증, 제어면을 기준선으로 확정한다.

## Provider 1차 구현체

- Twilio Programmable Voice Media Streams
- bidirectional `<Connect><Stream>` 사용을 전제로 설계
- provider inbound/outbound audio: `audio/x-mulaw`, 8 kHz, mono
- Twilio `connected/start/media/dtmf/mark/stop` 이벤트 정규화
- Twilio outbound `media/mark/clear` 생성
- 실제 provider mode에서는 `X-Twilio-Signature` 검증 필수
- `TELEPHONY_PROVIDER=twilio`일 때만 실제 provider 경로 활성화

## Server TTS 1차 구현체

- OpenAI `POST /v1/audio/speech`
- 기본 모델 `gpt-4o-mini-tts`
- 기본 voice `coral`
- PCM 응답을 Gateway에서 전화망용 μ-law 8 kHz mono로 변환
- 기본 PCM 입력률은 `OPENAI_TTS_PCM_RATE=24000`으로 구성 가능
- 답변 텍스트 2,000자 이하 제한
- TTS audio file/원문 DB 저장 없음

## Gateway 제어면

- `GET /health`
- `GET|POST /v1/twiml` — Twilio `<Connect><Stream>` 응답
- `POST /v1/tts` — `{callId,text}`를 받아 Server TTS 후 활성 provider WebSocket으로 음성 송출
- `POST /v1/clear` — 통화 중 buffered audio 중단
- WebSocket `/v1/media`

## 오디오 변환

- Twilio inbound μ-law/8k → PCM16/16k 내부 표준
- OpenAI TTS PCM → 8k downsample → μ-law encode → Twilio media payload
- v0.14는 단순 평균 기반 24k→8k resample 기준선이며, 실제 운영 전 고품질 resampler 비교 검증 필요

## 환경변수

### Gateway 공통
- `PORT`
- `TELEPHONY_PROVIDER` (`simulator` 기본, 실제 연결 시 `twilio`)
- `PUBLIC_MEDIA_WSS_URL`

### Twilio
- `TWILIO_AUTH_TOKEN`

### Server TTS
- `OPENAI_API_KEY`
- `OPENAI_TTS_MODEL` (기본 `gpt-4o-mini-tts`)
- `OPENAI_TTS_VOICE` (기본 `coral`)
- `OPENAI_TTS_PCM_RATE` (기본 `24000`)

## 안전/비용 기준

- 실제 Twilio 전화번호 미구매
- 실제 유료 PSTN 통화 미실행
- Browser TTS는 웹 PoC에 유지, 전화망은 Server TTS만 사용
- 실제 통화 음성/생성 음성 파일 DB 저장 없음
- provider/TTS 자격증명이 없으면 실제 provider path 비활성
- 실제 내부 승인근거/개인정보를 전화망에 연결하기 전에 인증·권한·보안심사 필요
