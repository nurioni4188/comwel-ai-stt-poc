# v0.13.0 Media Gateway Baseline

## 목표

v0.12.0의 provider-neutral Telephony Adapter와 기존 STT/RAG 엔진 사이에 장시간 연결을 담당하는 독립 Media Gateway 기준선을 둔다.

## 배치 원칙

- Vercel 웹앱: 관리 UI, 계약 inspection/validation API
- 별도 `gateway/` 서비스: persistent WebSocket media session
- 실제 전화사업자: 아직 미연결
- 실제 Server TTS: 아직 미연결

## WebSocket 계약

Endpoint: `/v1/media`

### 주요 입력

- `call.started`
- `audio.inbound`
- `dtmf.received`
- `audio.outbound`
- `audio.clear`
- `call.handoff`
- `call.hangup`
- `call.stopped`

### Gateway 응답

- `gateway.ready`
- `audio.accepted`
- `audio.outbound.accepted`
- `audio.cleared`
- `call.handoff.accepted`
- `call.closed`
- `gateway.error`

## 내부 오디오 기준

- codec: `pcm_s16le`
- sampleRate: 16000
- channels: 1

실제 provider가 μ-law 8k, A-law, Opus 등을 사용하면 provider adapter 또는 media transcoder가 내부 표준으로 변환한다.

## 연결 안정성

- heartbeat ping/pong 기본 15초
- max frame 기본 128 KiB
- message sequence는 call 단위 단조 증가
- 동일 callId 중복 시작 거부
- 비정상 frame은 해당 메시지만 `gateway.error`
- SIGTERM/SIGINT 시 연결 종료 후 graceful shutdown

## 보안 기준선

- 실제 민원 음성 저장 없음
- raw audio DB 적재 없음
- provider secret은 Gateway 환경변수로만 주입
- 외부 provider 연결 시 signature/token 검증 필수
- Gateway 공개 배포 전 TLS/WSS 필수
- 실제 내부 승인근거 사용 전 인증/권한 통제 필수

## v0.13.0 범위 밖

- 실제 PSTN/SIP 연결
- 실제 전화번호
- server-side TTS
- live STT streaming
- barge-in VAD 완성
- 담당자 SIP transfer 실제 실행
