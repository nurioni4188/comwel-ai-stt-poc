## upsert 검증

검증 세션: `24f5d408-faff-4b64-bf8d-aa041e1070a5`

운영 데이터에 영향을 주지 않도록 트랜잭션 내부에서 두 차례 저장 후 `ROLLBACK`했다.

1. `overall_rating = minor_edit` 저장
2. 동일 `session_id`에 `overall_rating = accurate` 재저장
3. 두 번째 저장 이후 해당 세션 평가행 수 `1` 확인
4. rating과 reviewer note가 두 번째 값으로 갱신됨을 확인
5. `ROLLBACK` 후 기존 persisted 평가가 복원되어 테스트 데이터가 남지 않음을 확인

결론: `ON CONFLICT(session_id) DO UPDATE` 재평가 upsert 정상.
